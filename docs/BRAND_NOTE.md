# Anvexia — working brand

**Anvexia** (अन्वेक्सिया) is a coined working name inspired by *anveshan* (exploration) and a modern, forward-looking sound. The product descriptor is **Science, brought to life.** / **विज्ञान को जीवंत देखिए।** The in-app mark is an original, inline vector letterform; no third-party logo asset or external service is needed. This is a brand refresh, not a claim that the offline app includes an AI assistant.

## Clearance before public launch

A limited web search for the exact spelling on 2026-11-24 returned no exact results. That is not a trademark, company-name, app-store, social-handle or domain clearance and does not prove the name is unique, royalty-free or legally available. Before public use, arrange a professional search for exact and confusingly similar marks in India and other launch territories, including software and education services; check domains and app stores separately. The working name may need to change based on that review.

Existing content attribution, third-party licence notices, internal file names, storage keys and data schemas are retained. The brand change does not alter the licence or ownership of underlying material.
